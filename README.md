# HabitFlow — Habit Tracker App (Built with Codex by Vibe Coding)

A complete single-page habit tracker with streaks, built **entirely by describing it in plain English** — no hand-written code. The app was generated by **Codex inside the ChatGPT desktop app (free plan)** using three prompts, exactly as shown in the video tutorial.

🎥 **Video tutorial:** "Vibe Coding for Beginners (2026) — Build & Deploy a Real SaaS App With Codex, Step by Step" on the **Simplified Dev Code Camp** YouTube channel.

## Features

- **Habit cards** with name, icon and current streak (🔥)
- **One-tap done toggle** — marking a habit done adds +1 to its streak; un-marking subtracts 1
- **Live progress** — progress bar, "X of N done" and percentage for today
- **Add your own habits** with the form above the list
- **Delete** any habit with the small × button
- **Best streak** stat in the progress section
- **Celebration banner** — "🎉 All habits complete - amazing work!" appears when every habit is done
- **Automatic saving** — everything persists in `localStorage` (key `habitflow-v1`), so the app remembers your habits and streaks between visits; a new day resets the done ticks but keeps the streaks

## Tech

- One single file: `index.html` (HTML + CSS + JavaScript all inline)
- No frameworks, no build step, no backend, no external libraries

## Run it

Just open `index.html` in any modern browser — or serve the folder with any static server, for example:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## The 3 prompts used in the video

1. **Build the app** — single-page habit tracker "HabitFlow" in one `index.html`: dark design with a green accent, header with app name and today's date, progress section (bar + "X of 4 done" + percentage), habit cards with streaks and a round check button, data in `localStorage` under `habitflow-v1`, seeded with 4 habits (Drink 2L of water — streak 2, done; Read 10 pages — streak 1; Morning run — streak 0; Meditate 5 minutes — streak 0). Toggling done adds +1 to the streak, un-marking subtracts 1.
2. **Add and delete** — an "Add a habit" form (input + Add button) and a small delete (×) button on every card; progress always uses the current number of habits, and saved data loads correctly with any number of habits.
3. **Finishing touches** — the all-done celebration banner with a pulse animation, plus a "Best streak" stat with a flame emoji.

Full prompt text: see the video description / `prompts.md` in the tutorial project.

## Deploy it free

This is a static single file, so it deploys free on **GitHub Pages** (Settings → Pages → deploy from `main`), Netlify Drop, Vercel or Cloudflare Pages — just publish the folder containing `index.html`.
